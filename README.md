# COVID-19 Data Analysis Project using Python and AWS Stack

This project aims to create a comprehensive big data pipeline that leverages various AWS tools such as AWS Lambda, AWS Glue, AWS S3, Amazon Redshift, Amazon EventBridge, and Amazon Quicksight to conduct intricate analysis on COVID-19 data.

## Overview
COVID-19 is an infectious disease caused by the novel coronavirus SARS-CoV-2. The disease was first identified in Wuhan, China, in December 2019 and has since spread rapidly worldwide, resulting in a global pandemic. COVID-19 primarily spreads through respiratory droplets when an infected person talks, coughs, or sneezes. Symptoms can range from mild to severe, including fever, cough, shortness of breath, fatigue, body aches, and loss of smell or taste. In severe cases, COVID-19 can lead to pneumonia, acute respiratory distress syndrome, and death.

## Data
Johns Hopkins University is a prestigious research university located in Baltimore, Maryland, United States. It is well known for its research and education in various fields, including medicine, public health, engineering, and business. In response to the COVID-19 pandemic, the university established the Johns Hopkins Coronavirus Resource Center, which is dedicated to tracking and reporting the latest data on the global impact of the virus. Johns Hopkins University also maintains a GitHub repository that contains up-to-date data on COVID-19 cases, deaths, and recoveries from around the world. The repository is publicly available and can be accessed by anyone interested in analyzing the data. The data is provided in a CSV (comma-separated values) format and is updated on a daily basis. It includes information on the number of confirmed cases, deaths, and recoveries, as well as other relevant data such as the date, country, and region.
